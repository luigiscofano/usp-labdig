# Contribuições

Para corrigir uma implementação, descreva o comportamento esperado e inclua uma forma de reproduzir o problema. Execute `python scripts/verificar.py` antes de enviar a alteração. Atualize o guia do projeto e `docs/CORRECOES.md` quando mudar interfaces ou protocolo.

Mantenha os originais intactos. Novas revisões devem entrar nas cópias de trabalho ou em uma pasta de versão identificada. Não misture módulos homônimos de experimentos diferentes em uma mesma compilação.

Nos objetivos pedagógicos, diferencie uma intenção de design de um resultado avaliado. Preserve a autoria dos componentes e a atribuição do trabalho em grupo.
