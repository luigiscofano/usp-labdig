## Como usar

Leia o relatório junto do circuito e de seu testbench. Uma compilação aprovada, uma simulação e um ensaio físico respondem perguntas diferentes. A documentação registra as verificações realizadas e mantém pendências de bancada explicitamente abertas.

## Apresentar o projeto

A [pasta de apresentações](../apresentacoes/README.md) reúne o roteiro e sua versão HTML. Use evidências ligadas ao alvo demonstrado; não aplique o resultado de um circuito a todas as variantes históricas.
